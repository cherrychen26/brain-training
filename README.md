# 每日脑力健身房 v2.0

面向中老年用户的中文本地 PWA：React、TypeScript、Vite、Tailwind CSS、IndexedDB。八种游戏都有题目生成、操作与实际判题。数据只保存在设备浏览器，没有账号、上传接口或虚构示范成绩。

## 使用

双击上一级的 `启动应用.cmd`，保持窗口开启，打开 http://127.0.0.1:5173/ 。本机已有依赖和正式构建。不要直接打开 dist/index.html。继续使用相同浏览器、用户配置和地址，旧 IndexedDB 存档会自动迁移，并在 snapshots 保留迁移前快照。

首页查看今日计划 → 开始今日训练 → 完成后自动切换 → 查看总结。可以暂停、跳过、提前结束；自动切换倒计时为 5 秒，查看答案会暂停。刷新、后台切换后暂停恢复；跨日保存结束旧训练，再生成新计划。尚未开始的项目可更换一次。

默认计划预算 8 分钟，可选 6/8/10 分钟；这是有效训练时间上限，不要求练满。正式训练与自由练习每天合计不超过 600 秒。暂停和项目间休息不计时。自由练习单次最多 150 秒，只保留记录，不重复影响难度与能力趋势。

首次打开正式版后在偏好设置等待离线资源就绪。浏览器支持时点击“安装应用”，也可使用浏览器安装菜单。完成缓存后断网可以继续训练和保存。更新提示在没有进行中训练时出现；旧安装版本若仍显示旧界面，请结束或保存训练后接受更新并刷新。

## 八种游戏及等级

所有项目独立保存 1～10 级，初始 1 级。

| 项目 | 实际判题与难度变化 |
|---|---|
| 舒尔特方格 | 按顺序找数字；1～3 级 3×3，4～7 级 4×4，8～10 级 5×5 |
| 数独 | 错误填写反馈，全部正确才完成；1～4 级 4×4，5～10 级 6×6，随等级增加挖空目标，每题保持唯一解 |
| 24 点 | 四数各一次、精确有理数运算；低/中/高级数字上限 6/9/13，以最简解运算复杂度筛选随机题目；拒绝非法算式和除零，不执行代码 |
| 翻牌记忆 | 真实配对；4～8 对图案，初始展示约 6.55～2.5 秒，可提前开始翻牌 |
| 推箱子 | 箱子全部到目标才完成；1～3 个箱子、6×6 或 7×6 地图，高等级加入障碍；用 BFS 最短步数筛选，目标约 2+等级×2 步 |
| 数字记忆 | 每轮 3 组，逐位判题；数字长度 3～9 位，展示约 7.6～4 秒 |
| 规律推理 | 每轮 4 题、四选一；1～3 级等差，4～6 级交替增量，7～10 级递增增量，提供规律解释 |
| 反应与注意力 | “按”点击、“停”等待；正确命中和正确抑制均计分，漏按和误按计错；12～18 个刺激，等级提高后刺激展示缩短 |

题目复杂度总体随等级提高，但不保证任意相邻两题严格更难。推箱子生成采用有界搜索，必要时回退到已验证的简单题；局面卡死可撤销或重来，提示找不到路径会如实说明。

## 每日计划和自适应

计划使用本地日期与设备用户标识生成种子，每天 3～5 类。周轮换覆盖八类，避免相邻日期完全相同组合。保存计划版本、种子、等级和实际题目；同日重新打开沿用原计划，完成或主动结束后不重新计分。最近 14 天的题目指纹用于有界重试去重，不能保证永远不重复。可选游戏不足时有界减少项目数量。

统一参数：`src/domain/config.ts`。综合表现 = 正确率 55% + 完成速度 15% + 少用提示 10% + 完成情况 20%。完成速度优先参考个人最近最多 10 次同项目、同等级成功记录的用时中位数，至少 3 个样本，否则使用默认参考时间；基准受上下界保护。

- 最近 5 次同类有效记录才评估。完成与超时有效；主动跳过、提前结束及自由练习不用于调整。
- 平均正确率至少 90%，至少 4 次完成且较快，最近 2 次连续完成，平均提示不超过 1 次，综合分至少 86 分：提高 1 级。
- 平均正确率低于 60% 且至少 3 次困难，或最近 3 次连续困难且综合分低于 56 分：降低 1 级。
- 其他情况保持；每次改变后至少再观察 3 条有效记录；限制在 1～10 级。
- 超时与主动跳过分开记录；单次异常不会直接造成大幅降级。游戏间的等级互不影响。

## 报告与存档

首页、训练、报告、历史、设置均保留并完善。报告展示近 7/30 天练习日期、计划完成天数、规律性、自然周总结，以及可筛选的 7/30/90 天趋势。比较先匹配游戏和等级；个人历史基线至少 3 条。样本不足时明确显示，不编造进步。小成就只使用真实完成记录，不要求连续打卡。

每条记录包含日期、项目、等级、正确率、时间、错误、提示、结果、综合评分、调整前后等级及原因、答案说明。不同游戏的正确率定义不同，不直接当作能力排名。所有结果只描述训练表现，不能用于痴呆风险诊断或医学疗效判断。

原数据库仍为 `daily-brain-gym`，原 state/snapshots 保留。状态变化排队保存，计时约每 250ms 更新；突然断电仍可能损失尚未提交的最后少量状态。支持单写入窗口锁，避免两个窗口互相覆盖。

JSON v2 备份含历史、设置、独立等级、用户标识、全部计划、种子、题目与未完成棋盘；兼容 v1。最多 100 MB / 100000 条成绩；导入前校验题目和状态，整份拒绝畸形文件。按 ID 去重合并，保留本机冲突记录；已有设备保留本机等级，新设备恢复备份等级。导入前自动存快照。训练进行中禁止导入。换浏览器或端口意味着独立存档，请用 JSON 迁移。

## 项目结构

- src/domain/config.ts：集中算法参数
- src/domain/adaptive.ts：独立难度、个人速度基准、同级比较
- src/domain/planner.ts、session.ts：每日计划、恢复、计时与训练流程
- src/domain/analytics.ts：近期统计和能力方向对比
- src/games/：八种游戏生成器、判题、求解与去重指纹
- src/storage/：IndexedDB、迁移、备份与完整性校验
- src/components/：游戏交互、计划更换、历史、趋势与成就
- src/App.tsx：页面、计时保存、单窗口锁和 PWA 更新
- src/upgrade.css：新增题型和报告布局
- tests/：规则、持久化、30 天模拟及浏览器验收
- dist/：正式 PWA

## 开发与验收

本机无需安装新依赖。项目目录内运行：

```powershell
npm.cmd run dev -- --port 5174 --strictPort
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --port 5173 --strictPort
```

正式版浏览器验收（独立 Edge 测试配置，不写个人成绩）：

```powershell
$env:TEST_BASE_URL='http://127.0.0.1:5173'
$env:TEST_PRODUCTION='1'
npm.cmd run test:e2e
```

构建配置保留旧产物，不清空 dist；测试截图和输出使用任务 work 下的新目录。2026-10-20 验收结果详见上一级《升级说明与验收报告_v2_20261020.md》。真实 iOS/Android、系统级安装和屏幕阅读器尚未真机验证。

GitHub Pages 使用独立的 `npm run build:pages` 和 `/brain-training/` 路径；本地开发与原 dist 构建不变。推送 main 后自动测试并部署，操作与数据迁移说明见 [DEPLOYMENT.md](DEPLOYMENT.md)。网站地址：https://cherrychen26.github.io/brain-training/ 。
